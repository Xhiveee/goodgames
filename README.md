# gg.xhiveee.ru

Игровая площадка на React, TypeScript и Three.js. В проекте есть пять игр: Слизарио с ботами, сапёр с тремя размерами поля, динозаврик с прыжком и уклонением, змейка с ускорением и судоку с уникальными сетками. Учётные записи и сохранение результатов не используются.

## Запуск

```sh
npm install
npm run dev
```

## Онлайн-арена

Онлайн-режим использует отдельный Node.js сервер. Одна общая арена поддерживает до 20 подключённых игроков.
Сервер синхронизирует позиции, еду и очки; столкновения пока проверяются на клиентах.

Для локальной игры запусти сервер и Vite в отдельных терминалах:

```sh
npm run server
npm run dev
```

WebSocket-сервер слушает порт `8787`; проверка состояния доступна на `/healthz`. Для production размести сервер на Node.js-хостинге и настрой HTTPS reverse proxy для WebSocket-подключений. При сборке сайта укажи публичный адрес сервера:

```sh
VITE_SLITHER_SERVER_URL=wss://games.example.com/slither npm run build
```

В PowerShell:

```powershell
$env:VITE_SLITHER_SERVER_URL='wss://games.example.com/slither'
npm run build
```

Если переменная не задана, клиент подключается к текущему домену на порту `8787`.

## Деплой на VPS

Для деплоя нужны Debian или Ubuntu и домен, указывающий на VPS. Скрипт устанавливает nginx, Docker и Certbot, не заменяет конфиги других сайтов и создаёт отдельный сайт nginx для указанного домена. Nginx слушает порты `18081` и `8443`, чтобы не занимать стандартные порты Xray (`80` и `443`). Настрой Xray reverse proxy для домена: HTTP перенаправь на `127.0.0.1:18081`, HTTPS — на `127.0.0.1:8443` с передачей исходного `Host` и поддержкой WebSocket. Публичный HTTP-порт должен быть доступен Certbot для проверки домена.

Запусти команду от пользователя с `sudo`, указав домен и email для Let's Encrypt:

```sh
curl -fsSL https://raw.githubusercontent.com/Xhiveee/goodgames/main/deploy/install.sh | sudo bash -s -- gg.xhiveee.ru admin@example.com
```

Скрипт скачивает актуальный исходный код, собирает Docker Compose сервисы сайта и онлайн-арены, получает HTTPS-сертификат и включает автоматическое продление через `certbot.timer`. Nginx хоста принимает запросы на `18081` и `8443`; конфиг создаётся в `/etc/nginx/sites-available/goodgames-<домен>.conf`. Приложение доступно nginx только на `127.0.0.1:18080`.

Для повторного деплоя выполни ту же команду. Файлы проекта размещаются в `/opt/goodgames`.

Проверка production-сборки:

```sh
npm run build
npm run preview
```

Файл `public/CNAME` содержит домен `gg.xhiveee.ru` для статического хостинга. Для публикации укажи этот домен в настройках хостинга и добавь DNS-запись, которую выдаст хостинг.
